# Solar Linear icons

Icons by [480 Design](https://www.figma.com/community/file/1166831539721848736),
licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

StuDash bundles a subset of the original Linear SVG artwork from
[@iconify-json/solar 1.2.14](https://www.npmjs.com/package/@iconify-json/solar/v/1.2.14).
The artwork is rendered with the theme's current color and sized to fit each control.
